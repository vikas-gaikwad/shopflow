# ShopFlow

A production-style e-commerce and order management
learning project built from scratch.

## Technology baseline

- Java 25
- Spring Boot 4.1.1
- Maven
- PostgreSQL
- Flyway
- Git and GitHub

## Development approach

1. Build the basic backend flow.
2. Evolve it into microservices.
3. Introduce security, messaging, resilience,
   caching, and observability.
4. Add containers and CI/CD.
5. Complete the automated testing phase.
6. Build the Angular frontend.

## Architecture

The initial backend will be a modular monolith.
Services will be extracted when their boundaries
and responsibilities are clear.
